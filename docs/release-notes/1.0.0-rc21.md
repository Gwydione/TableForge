# TableForge 1.0.0-rc21

Release candidate for external testing. TableForge turns random tables from RPG books and PDFs into fast, searchable,
rollable digital tables.

## Highlights

- New: **Owlbear Rodeo (Tables+) export**. On the Roll screen, **Export…** → **Copy Tables+ JSON** or **Save Tables+ JSON…**
  turns one result set into one table in the documented Tables+ JSON import shape (`name`, `type`, `dice`, `entries`).
  `d66` exports as `weighted` / `T66`, a real 66-sided die as `1d66`, `2d6` as `bell-curve`, and one die with a modifier
  (`d20+2`, `d20-2`) as `weighted`. Several dice with a modifier (`2d6+1`) are refused for now.
  **Checked in Tables+:** TableForge-exported `d20`, `d66` (`T66`, in the sample tested) and unmodified `2d6` tables
  imported and rolled correctly. A separate, hand-written `1d4+20` Tables+ table consistently rolled 21–24, which shows
  Tables+ applies a positive single-die modifier; that was not an end-to-end TableForge export test. Everything else is
  still untested in Tables+ (see Known Issues). Reports are welcome (see `docs/RELEASE_TESTING.md`).
- From rc20: **Copy for Sojour**. **Export…** → **Copy for Sojour** copies only the rows of one result set, ready to paste
  into a Sojour Lookup Table with **Ctrl+V**.
- From rc19: **Foundry VTT export**. **Export…** → **Copy Foundry JSON** or **Save Foundry JSON…** for Foundry's Roll Table
  Importer module (Foundry v13–v14).
- Everything from rc18: paste a table from a PDF or book, review and correct it, save it, find it and roll it; Built-in or
  dddice dice; linked tables, inline dice, several rolls at once.

## Installation

1. Download `TableForge-1.0.0-rc21-Setup.exe` below.
2. Run it. It installs for your Windows user only, with no administrator prompt, into `%LOCALAPPDATA%\Programs\TableForge`.
3. Start **TableForge** from the Start Menu.

Requires 64-bit Windows 10 or 11. .NET is included. The Microsoft Edge WebView2 Runtime (part of Windows 11 and current
Windows 10) is needed only for dddice dice; Built-in dice always work.

This release candidate is **not code-signed**, so Windows SmartScreen may warn about it. If you trust this download, choose
**More info** → **Run anyway**. Check the file against `SHA256SUMS.txt`:
`Get-FileHash .\TableForge-1.0.0-rc21-Setup.exe` in PowerShell.

Also attached: `TableForge-1.0.0-rc21-win-x64.zip`, the same program without an installer (extract it and run
`TableForge.exe`; it uses the same data folder).

## What's Included

- Paste Table with a conservative parser and a Review/Correct screen (PDF clean-up tools, multi-column result sets).
- Collections, folders, search, recent tables and recent rolls.
- Dice: `NdM` with an optional modifier (`2d6+1`), `d66`, and `d100` with `00`.
- Situational modifier, per-table clamp to range, inline dice, several rolls at once, linked tables.
- Copy Table Text: one result set as clean tab-separated text.
- Copy for Sojour: one result set's rows only, for pasting into a Sojour Lookup Table.
- Foundry VTT export: one result set as Roll Table Importer JSON, copied or saved as a `.json` file.
- Owlbear Rodeo (Tables+) export: one result set as Tables+ import JSON, copied or saved as a `.json` file.
- Optional dddice visual dice: guest mode, or connect your dddice account (via dddice.com, never your password) and choose a
  compatible theme from your Dice Box.
- Open Data Folder, About TableForge, LICENSE / PRIVACY / THIRD-PARTY-NOTICES.

## Known Issues

- Image-only or scanned PDFs need OCR first; TableForge reads the text you copy.
- Unusual PDF layouts may need manual cleanup on the Review screen, and TableForge does not find tables in a whole PDF.
- Copy Table Text is generic text, not a format for a particular VTT.
- Copy for Sojour was tested by pasting with Ctrl+V only. It copies rows, not the table's name, dice or links; line
  breaks and tabs inside a result become spaces.
- Foundry export needs the Roll Table Importer module, exports one result set at a time without links, and Foundry does
  not reproduce Clamp. Fantasy Grounds is not supported yet.
- Tables+ export has been checked in Tables+ only for `d20`, `d66` and `2d6` tables (see Highlights); this is not full
  Tables+ compatibility. Still untested there: negative modifiers and negative ranges, gaps and overlaps, `{2d6}` and
  `#reroll` in results, a real `1d66`, `d100`, a TableForge export with a single-die modifier, and importing a file saved
  with **Save Tables+ JSON…**. These are exported as written. Several dice with a modifier (`2d6+1`) are refused.
  Tables+ JSON has no Clamp setting.
- dddice needs internet and WebView2; connecting an account takes a few browser steps.
- Windows x64 only. Only one copy of TableForge should be open at a time.
- Not code-signed (see Installation).

## Data and Upgrades

Your tables and settings live in `%LOCALAPPDATA%\TableForge` (**Open Data Folder** shows it). Installing a newer version
keeps them; uninstalling TableForge does **not** delete them, and reinstalling finds them again. To back up, close
TableForge and copy that folder. If a future version needs to update the data format, it makes an automatic safety copy of
the database first.

## Feedback
