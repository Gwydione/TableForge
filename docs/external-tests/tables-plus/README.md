# Tables+ import fixtures

Small tables written by TableForge's Tables+ export, one per behavior to check in Owlbear Rodeo's Tables+ extension. They
are generated by `TablesPlusFixtureTests` and a test fails if they drift from what the exporter writes. That proves the
JSON shape only. As of 2026-09-27, `d20`, `d66` (`T66`) and `2d6` TableForge exports have been imported and rolled
correctly in Tables+; the other fixtures are **untested there**. The checklist is in
`docs/RELEASE_TESTING.md` under "Owlbear Rodeo (Tables+)".

There is deliberately no `2d6+1` fixture: TableForge refuses several dice with a modifier until Tables+ is known to
handle them.
